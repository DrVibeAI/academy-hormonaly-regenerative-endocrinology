Source: Hormonaly course package 1.1.0 at SHA256 `6419297d6d012d8c8e5b58909e9e9f1f950443aa548ca20618017dbb0ebfa4fa`. User request dated 2026-09-29: Cenegenics es-MX/Mexico, Biolongeva pt-BR/Brazil held for its launch, Parallaxnet Healthcare id/Indonesia.

The three `*-locale-selection.json` files are **minimal internal planner inputs**, not schema-valid customer briefs or customer approvals. The formal Tier-2 brief check remains open because partner contact, claims, rights, reviewer and rollout details are not supplied. `*-locale-plan.json` is the Foundry job inventory produced from those selections. It reported 3,797 missing target text fields for each language before drafting.

`*.draft.json` and `candidates/` are machine-assisted translations and private course candidates. `QUALITY-FLAGS.json` and `QA-REPORT.md` record structural checks and review pointers. `LOCAL-CONTEXT-JOBS.json` flags 289 learner/assessment/tutor fields containing source-brand, US regulatory or culture-specific wording for per-country review; `REGULATORY-JOBS.json` separately lists the 30 moments with jurisdiction variants. `REGULATORY-REVIEW.md`, `MEDIA-PLAN.md`, `RUNTIME-GAPS.md` and `INTEGRATION.md` describe work still needed before a learner can receive an edition.

Reviewer handoff files in `review/` pair all 3,796 retained English source text fields with each target draft in CSV format, mark local-context and regulatory passages, and extract seven film narration drafts per language. Reviewers should record changes in a new candidate revision tied to this source hash; the CSV `review_status` column is deliberately `unreviewed` throughout. `translate-runtime-id.mjs` generates an isolated shared-runtime Indonesian UI draft, not a live learner language.

No live source package, partner academy, store pin, accreditation, certificate or public traffic was changed. All partner approvals and media are deliberately draft.
