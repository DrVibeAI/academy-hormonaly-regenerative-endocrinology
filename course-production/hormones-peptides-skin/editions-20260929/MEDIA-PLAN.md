# Localized media inventory · draft

Source package 1.1.0 carries **seven English module-opener films** (m01–m07, roughly 67–84 seconds each), seven posters and 48 text-free teaching illustrations. The opener blocks mark their English captions as **burned into the video**, and the package has **no separate caption assets**. A new audio track or VTT alone would leave visible English captions, so each target-language opener needs a new render. The Hormonaly landing trailer is configured in `academy.yaml`, outside the package.
